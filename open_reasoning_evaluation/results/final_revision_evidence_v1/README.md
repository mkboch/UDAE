# Final Revision Evidence V1

This folder is reserved for the final reviewer-response evidence package.

It should contain:
- reviewer gap matrix
- full-run inventory and audit
- precision/load-mode audit
- model/tokenizer/software manifest
- sample ID manifest
- prompt and extraction-rule checksums
- Phi parser diagnostics
- weighted-score sensitivity
- bootstrap/repeated-subset stability
- paired permutation/Holm correction summaries
- MC prompt ablation V3 full-500 summary

This folder is intentionally separated from raw experiment folders so the revised paper and response letter can cite one consolidated evidence location.
